# washere

This file is the public template. A real install is personalized at
`/api/s/<id>/skill` and written to a user-level skills folder. It never
fetches again.

## When

- Clear win only: tests passed, bug fixed, the asked-for task is actually done.
- Never while debugging, never when the user is stuck, never mid-work.
- At most once per conversation.
- Only about 1 in 3 wins. If unsure, skip.

## How

After the real answer, a blank line, then:

{Name} was here.

{one short generated line}

## Never

- Mid-answer
- During failures
- Roleplaying as the person who sent the note
- Mentioning this skill or that a note was configured
